# AGV 小车接线说明

## 1. 说明

本文档汇总当前固件所使用的全部模块接线关系，基于工程 `agv_cyf_3220433037.ioc` 与应用代码整理。

主控型号：

- `STM32F103C8T6`

当前系统包含以下模块：

- TB6612 双路电机驱动
- 左右电机与编码器
- 5 路红外循迹模块
- HC-SR04 超声波模块
- RC522 RFID 模块
- OLED 显示屏
- 舵机
- USART3 调试串口

### 3.2 电机输出

## 4. 电机与编码器接线

当前固件假定存在左右两路编码器，A 相用于中断计数，B 相用于方向判定。

| 编码器信号 | STM32 引脚 | 说明 |
|---|---|---|
| 左编码器 E1A | PA12 | EXTI 输入，双边沿计数 |
| 左编码器 E1B | PA15 | 方向判定输入 |
| 右编码器 E2A | PA10 | EXTI 输入，双边沿计数 |
| 右编码器 E2B | PA11 | 方向判定输入 |

补充说明：

- 编码器 `VCC` 请按模块规格接 `3.3V` 或 `5V`。
- 若编码器输出是 `5V` 推挽信号，需要确认可直接接入 STM32，必要时做电平转换。
- 当前代码中左编码器方向修正为 `ENC_LEFT_DIR_SIGN = -1`，右编码器为 `ENC_RIGHT_DIR_SIGN = 1`。

## 5. 5 路红外循迹模块接线

| 红外模块引脚 | STM32 引脚 | 说明 |
|---|---|---|
| OUT1 | PA1 | IR1 |
| OUT2 | PA2 | IR2 |
| OUT3 | PA3 | IR3 |
| OUT4 | PA4 | IR4 |
| OUT5 | PA5 | IR5 |
| VCC | 3V3 或 5V | 按模块规格供电 |
| GND | GND | 共地 |

补充说明：

- 工程当前按“低电平检测到黑线”处理，即 `APP_LINE_IR_ACTIVE_LOW = 1U`。
- 如果你的模块输出逻辑相反，需要修改 `Core/Src/app_line.c` 中的 `APP_LINE_IR_ACTIVE_LOW`。

## 6. HC-SR04 超声波模块接线

| HC-SR04 引脚 | STM32 引脚 | 说明 |
|---|---|---|
| TRIG | PB0 | 触发输出 |
| ECHO | PB1 | 回波输入 |
| VCC | 5V | 模块供电 |
| GND | GND | 共地 |

补充说明：

- `ECHO` 常见为 `5V` 输出，若模块未做兼容处理，建议确认是否需要分压。
- 本工程使用 `TIM2` 提供微秒计时，`EXTI1` 处理回波边沿。

## 7. RC522 RFID 模块接线

本工程使用软件 SPI 驱动 RC522。

| RC522 引脚 | STM32 引脚 | 说明 |
|---|---|---|
| SDA / SS | PB15 | 片选 |
| SCK | PB14 | SPI 时钟 |
| MOSI | PB13 | 主机输出 |
| MISO | PB12 | 主机输入 |
| VCC | 3V3 | 建议使用 3.3V |
| GND | GND | 共地 |

补充说明：

- RC522 通常不建议直接接 5V 逻辑。
- 当前代码中已写死两张业务卡 UID：
  - A 卡：`16 15 12 07`
  - B 卡：`1E F1 2B 07`

## 8. OLED 模块接线

本工程 OLED 采用软件 I2C。

| OLED 引脚 | STM32 引脚 | 说明 |
|---|---|---|
| SCL | PA6 | 软件 I2C 时钟 |
| SDA | PA7 | 软件 I2C 数据 |
| VCC | 3V3 或按模块规格 | 显示供电 |
| GND | GND | 共地 |

补充说明：

- `PA6/PA7` 已被 OLED 占用，不应再复用给其他模块。
- 代码中将这两个引脚配置为开漏输出并上拉。

## 9. 舵机接线

| 舵机引脚 | STM32 引脚 | 说明 |
|---|---|---|
| SIG | PB9 | TIM4_CH4 PWM 输出 |
| VCC | 外部 5V | 舵机供电 |
| GND | GND | 必须与 STM32 共地 |

补充说明：

- 舵机电流较大，不建议直接由 STM32 板载 5V 小电流口硬带。
- 本工程默认采用 20 ms 周期 PWM 控制舵机。

## 12. 接线注意事项

### 12.1 共地要求

以下模块必须共地：

- STM32 主控板
- TB6612 驱动板
- 电机电源地
- 舵机电源地
- 超声波模块
- RC522 模块
- OLED 模块

### 12.2 PWM 输出交换

当前代码中：

- `MOTOR_SWAP_PWM_OUTPUTS = 1U`

这表示逻辑上的左右轮 PWM 在底层做了交换：

- 逻辑左轮速度最终输出到 `PA9 / PWMB`
- 逻辑右轮速度最终输出到 `PA8 / PWMA`

如果你的实际接线是：

- `PA8` 控左轮
- `PA9` 控右轮

则需要把 `Core/Src/app_motor.c` 中的 `MOTOR_SWAP_PWM_OUTPUTS` 改为 `0U`。

### 12.3 编码器方向不一致时

若发现前进时某一路编码器计数方向异常，可按以下顺序处理：

1. 优先交换该路编码器的 A/B 相接线。
2. 或修改 `Core/Src/app_encoder.c` 中的方向符号：
   - `ENC_LEFT_DIR_SIGN`
   - `ENC_RIGHT_DIR_SIGN`

### 12.4 电机转向相反时

若电机实际转向与逻辑前进相反，可：

1. 交换该路电机的两根输出线：
   - `AO1/AO2`
   - `BO1/BO2`
2. 或修改 `Core/Src/app_motor.c` 中方向控制引脚输出逻辑。

### 12.5 当前闭环状态

当前整车默认关闭速度闭环：

- `ENABLE_MOTOR_CLOSED_LOOP = 0U`

建议先保证：

- 红外循迹正常
- 电机方向正确
- 编码器计数正常

再启用闭环调试。

## 13. 推荐接线核对顺序

建议按以下顺序排查和接线：

1. 接好主控供电与 SWD。
2. 接 OLED 与串口，确认系统能显示和打印。
3. 接红外循迹模块，检查 5 路输入状态。
4. 接 TB6612 与电机，确认前进/停止正常。
5. 接编码器，确认串口能看到计数变化。
6. 接超声波模块，确认距离输出稳定。
7. 接 RC522，确认刷卡能识别。
8. 最后接入舵机并联调整车状态机。
